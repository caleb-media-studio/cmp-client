# Optional CMP Cloud client companions

These are optional public client-side adapters for managed CMP Cloud.
The proprietary Cloud backend owns agent identities, WebSocket streams,
presence and work contracts, claims, session archive storage, indexing
and retention policies.

Client host adapters can normalize supported visible lifecycle events,
redact secrets before permitted upload, and retain encrypted retry
buffers. There is no hidden reasoning capture, automatic binary patching
or silent import of entire user transcript folders.

Self-hosted CMP Core never implements or promises the corresponding
Cloud-only server methods. Cloud methods must be capability-negotiated;
unsupported endpoints reject those operations before data transmission.

The previous private-history development demos using CMP Server's now
removed coordination/archive runtime are not normative or published here.
